吉吉编辑软件 v0.3.0：Windows 独立桌面编辑窗口。

### 本次更新

- 双击 Windows 应用直接进入编辑器，使用独立窗口，不再选择浏览器或复制地址。
- PDF 导出使用系统“另存为”对话框；取消保存会保留未保存状态，关闭时提醒尚未保存的修改。
- 编辑窗口显示异常时保留后台文档，提供应急 PDF 导出入口。
- 保留批量裁剪、撤销重做、页面整理、文字编辑与本机文件转换。
- 从真实 Windows ZIP 解压后验证内嵌 WebView2 中的页面加载、批量裁剪、撤销、PDF 保存、取消保存和关闭保护。

### 选择下载包

- Windows 10 / 11（64 位 Intel/AMD）：`Windows-x64.zip`，解压后运行 `JijiEditor.exe`。
- Mac Apple Silicon（M 系列）：`macOS-arm64.zip`。
- Mac Intel：`macOS-x86_64.zip`。

三种包都包含 Python 与 PDF 引擎，无需手动安装 Python。每个包附带项目源码、第三方许可；对应的 SHA-256 校验文件单独提供下载。

### 功能

PDF 裁剪、旋转、删页、排序、合并、提取；中文添加与横排文字局部替换；高亮、画笔、图片；撤销重做；无水印导出。图片/TXT 可直接转 PDF，Word/Excel/PPT 转换需要独立安装免费的 LibreOffice。

### 验证与限制

发布流程在每个对应系统运行核心测试，并启动打包后的程序验证预览、中文文字添加、批量裁剪、整批撤销与 PDF 导出。Windows 另验证真实独立窗口内的操作和保存流程。

未购买商业代码签名，Mac 未经 Apple 公证；Mac 目标 macOS 13+，旧系统尚需实机验证。不提供 OCR、任意段落重排或云同步；退出前请导出。Windows 使用内嵌 WebView2 和 .NET Framework 4.8。大多数较新 Windows 10 / 11 已有这些组件；缺少 WebView2 时会引导联网安装微软组件，安装后编辑文档可离线进行。更详细的使用与安装说明见仓库 README。
