吉吉编辑软件 v0.3.1：Windows 完整免安装版。

### 本次更新

- Windows 下载包带齐 .NET 10、WebView2、Python 与 PDF 引擎，完整解压后双击即可打开，无需另装运行组件，首次启动即可离线使用。
- PDF 导出使用系统“另存为”对话框；取消保存会保留未保存状态，关闭时提醒尚未保存的修改。
- 编辑窗口显示异常时保留后台文档，提供应急 PDF 导出入口。
- 保留批量裁剪、撤销重做、页面整理、文字编辑与本机文件转换。
- 在限制外网访问的环境中，从真实 Windows ZIP 解压运行，核对实际加载的运行组件来自包内，并验证页面加载、批量裁剪、撤销、PDF 保存、取消保存和关闭保护。

### 选择下载包

- Windows 10 / 11（64 位 Intel/AMD）：`Windows-x64.zip`，解压后运行 `JijiEditor.exe`。
- Mac Apple Silicon（M 系列）：`macOS-arm64.zip`。
- Mac Intel：`macOS-x86_64.zip`。

三种包都包含 Python 与 PDF 引擎，无需手动安装 Python。Windows 包另外包含完整 .NET 和 WebView2 运行环境，体积比 v0.3.0 大。每个包附带项目源码、第三方许可；对应的 SHA-256 校验文件单独提供下载。更新时先导出并关闭旧版，再替换整个应用文件夹，不要只复制 EXE。

### 功能

PDF 裁剪、旋转、删页、排序、合并、提取；中文添加与横排文字局部替换；高亮、画笔、图片；撤销重做；无水印导出。图片/TXT 可直接转 PDF，Word/Excel/PPT 转换需要独立安装免费的 LibreOffice。

### 验证与限制

发布流程在每个对应系统运行核心测试，并启动打包后的程序验证预览、中文文字添加、批量裁剪、整批撤销与 PDF 导出。Windows 另验证真实独立窗口内的操作和保存流程。

未购买商业代码签名，Mac 未经 Apple 公证；Mac 目标 macOS 13+，旧系统尚需实机验证。不提供 OCR、任意段落重排或云同步；退出前请导出。Windows 请解压到本机普通文件夹，不支持从网络共享目录运行；随包运行组件通过吉吉新版更新。Word/Excel/PPT 转换仍使用单独安装的 LibreOffice，PDF 编辑不需要它。更详细的使用与安装说明见仓库 README。
