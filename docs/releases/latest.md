吉吉编辑软件 v0.3.2：Windows 启动检查与诊断更新。

### 本次更新

- 启动前创建并检查软件用户目录的读写能力。
- 启动失败时显示具体阶段、Windows build 和错误码，提供“复制诊断信息”按钮。后台服务失败、显示环境创建失败和页面载入失败可分别识别。
- 自动保存经过过滤的诊断报告；常用报告目录不可写时尝试系统临时目录。报告不包含文档内容、会话令牌或原始异常消息。
- 提供适用于完整 v0.3.1 的小型启动更新包，避免再次下载约 400 MB 的完整 Windows 包。

**此版本改善启动检查和故障定位。目前尚未取得目标 Windows 10 1809 机器的具体错误码，也未完成该系统实机验证，不能确认其原有启动问题已解决。** 如果仍打不开，请点击“复制诊断信息”并反馈。

### 已有 Windows v0.3.1

下载 `JijiEditor-0.3.2-Windows-startup-update.zip`：

1. 导出文档并退出吉吉。
2. 将 ZIP 中全部文件解压到原 `JijiEditor.exe` 所在文件夹，选择替换同名文件。
3. 双击原文件夹中的 `JijiEditor.exe`。

小型更新不能独立运行，不适用于 v0.3.0 及更早版本。它保留原有文档处理与显示组件；更新后主窗口/诊断版本为 0.3.2，编辑页面仍显示 0.3.1，属于正常情况。保留原 `Source.zip`，新的启动器对应源码另附于 `Startup-update-Source.zip`。

### 首次使用或整体更新

- Windows 10 / 11（64 位 Intel/AMD）：`JijiEditor-0.3.2-Windows-x64.zip`，完整解压后运行 `JijiEditor.exe`。
- Mac Apple Silicon（M 系列）：`macOS-arm64.zip`。
- Mac Intel：`macOS-x86_64.zip`。

Windows 完整包包含 .NET、WebView2、Python 与 PDF 引擎，无需另装这些运行组件或选择浏览器。PDF 编辑可离线使用。不要只移动 EXE；整体更新请替换完整应用文件夹。每个下载包附带对应源码、第三方许可及公开 SHA-256 校验值。

### 验证与限制

发布流程运行核心测试、打包后 PDF 引擎验证和真实 Windows 独立窗口验证，包含批量裁剪、撤销、PDF 保存、取消保存、关闭保护、应急导出与诊断过滤。完整 Windows 包在限制外网连接的环境验证。小型更新会实际覆盖到经过 SHA-256 校验的公开 v0.3.1 包，再运行原生窗口验证。自动测试使用 Windows Server 2022，不能替代所有 Windows 版本的实机测试。

未购买商业代码签名，Mac 未经 Apple 公证，目标 macOS 13+。Windows 请解压到本机普通文件夹，不支持网络共享目录。Word/Excel/PPT 转 PDF 仍需独立安装 LibreOffice；PDF 编辑不需要。退出前请导出文档。详细使用说明见仓库 README。
