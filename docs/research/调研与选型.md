## 为什么这么实现

从零写 PDF 解析器耗时很大，也容易造成字体、坐标或输出文件兼容性问题。因此独立实现中文界面、文档会话、编辑操作、错误回滚、本机服务与桌面壳，底层复用成熟的免费 PDF 引擎。

- **转换**：图片、文本直接生成 PDF；Office 交给本地 LibreOffice。修正 headless 引擎字体发现配置，避免中文虽可复制但页面看不见的问题。
- **页面**：浏览器归一化坐标 → 旋转逆变换 → PDF 坐标；连续裁剪时补上 CropBox 偏移。
- **修改文字**：获取横排文本行并校验目标，删除该行文本对象，再用新文字绘制。失败时恢复旧快照，避免删了原文却没有成功插入。
- **中文**：通过 PyMuPDF 的 HTML 文本布局和字体回退绘制，保存后再读取和渲染确认。
- **桌面**：Mac 原生 WebKit 窗口；Windows 使用启动窗口和默认浏览器。两者均连接只监听本机的 Python 服务，下载包包含解释器和 PDF 引擎。v0.1.1 加入 Windows x64、Mac Apple Silicon 和 Mac Intel 的独立构建与打包验证，实际发布结果以 GitHub Actions 和 Releases 为准。

## 已完成与后续

第一版已经实现：格式转换、常用页面编排、局部文字替换、画笔/高亮/图片、撤销重做、无水印导出。

后续候选而非已实现：扫描件 OCR、段落重排、可编辑对象移动、PDF 表单设计、安全涂黑、批量转换队列、Windows 安装器、Apple 签名公证、崩溃恢复。完整办公套件可逐步扩展，不能把当前 PDF 编辑器称为完整 WPS 替代品。
